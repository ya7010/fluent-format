# Change Log

## [0.1.0] - 2026-02-14

### Added
- Initial release
- Document formatting provider for Fluent (.ftl) files
- Language configuration (syntax highlighting, auto-closing pairs, comments)
- Configuration option: `fluentFormat.sortOnFormat`

### Features
- Integrates with VSCode's standard formatting system
- Format on save support via `editor.formatOnSave`
- Optional message sorting within blank-line-separated groups
